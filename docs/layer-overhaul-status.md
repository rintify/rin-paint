# レイヤー刷新の実装状況

この変更は承認済みプランの途中段階であり、プラン全体の完了条件を満たしていない。
特に `src/model/document` と `src/engine/raster` の新基盤は、既存エディターの永続モデルやツールにはまだ接続されていない。

## エディターに接続した変更

- キャンバス／トランスフォームのレイヤー定義、追加メニュー、パラメータ編集、既存履歴でのUndo/Redoと復元。
- キャンバス内部を透明面から合成し、外部へ透明度・合成モードを一度適用。
- 一般レイヤーへの子の追加を拒否。ヒエラルキーのキャンバス展開を字下げなしに変更。
- キャンバス長押しによる子孫選択を撤去。選択を同一スコープに制限。
- SceneQueryによる同一スコープ／未満のマスク候補判定。無効な指定を残し、警告を表示。
- 明示マスクが全て無効な色補正は素通し。
- ピッカー、スナップ、塗りつぶし用の選択合成、内部色取得の対象を現在スコープへ制限。
- トランスフォームの逆変換領域を描画し、ページ外の図形をページ内へ戻せる数値変形を追加。
- Canvas2Dのアフィン経路、WebGL2の逆射影サンプリング、同期CPUフォールバック。
- 吹き出し／コマをキャンバスと直接の子による構造へ変更。
- 親への転写を、同一スコープ内のラスターをGUIで指定する操作へ変更。
- 自動保存開始時にページID・表示・サムネイル・履歴を捕捉。ページとメタ情報を同じIndexedDBトランザクションで保存。
- キャンバスマスクのキャッシュキーに子孫の変更・表示状態・順序を反映。

## 新基盤の実装と単体検証

- `src/model/document/types.ts`: 所有ドキュメント、実体、配置、スコープ、項目参照、構造差分の型。一般実体に親子フィールドを持たせない。
- `LinkResolver`: 読み取り時の項目解決、参照連鎖、項目変更／再リンク、循環とビン→ページ参照の拒否。
- `ScopeResolver`: 元構造、削除差分、ローカル追加、編集順の配置差分による子一覧の解決。
- `ProjectRepository`: 候補グラフの検証後に置換。ビン用Readerからページを参照できないAPI。
- `CommandService` / `DocumentSession`: ドキュメント別履歴と表示・選択状態の分離。
- `BinService`: 登録とページの参照元変更の分離、ビン編集をページUndoで巻き戻さないモデル操作。
- `SparseRaster`: 符号付き256pxタイル、不変タイル共有、変更タイルのCOW、透明タイル削除、疎な再サンプル。
- `RasterStore`: 圧縮タイル、リビジョン別索引、共有リソースの重複排除、アーカイブ、容量制限付きデコードLRU、参照リビジョンを根とした回収。
- `geometry/homography.ts`: 行列合成・逆行列・共役変換・4点からのホモグラフィ・無効四角形と射影地平線の判定。

これらの単体検証は、GUIからの一連の完成を示すものではない。

## 残作業

1. LayerService、ParameterLinkService、HistoryService、保存形式を新ドキュメントモデルへ移す。既存のparentId／childIdsとコピー同期への依存は残っている。
2. キャンバスの独自変更子の削除保護、リンク元削除時の自動独立化、削除Undo時の条件付き再リンク、子孫を含む完全な構造差分処理を完成する。
3. ビン登録時の入れ子・独自子・内部参照の対応を完成し、不要なページ実体を残さない。登録・リンク・履歴のモデルをUIへ接続する。
4. ラスターの実体を既存のページ大CanvasからRasterStoreへ変更。ペン・消しゴム・塗りつぶし・ぼかし・履歴パッチ・書き出しを接続する。
5. 図形、文字、画像、各ツールの既存px値をmm保存へ統一。所有／共有の判定を用いたページPPI再サンプルを接続する。
6. 合成をタイル領域要求へ移す。現状のトランスフォーム入力は外接矩形を確保し得るため、離れた素材や射影地平線付近でのメモリ保証は未達。
7. Workerフォールバックと描画／GPUキャッシュの合計容量制限を実装する。現在のCPUフォールバックは同期実行。
8. TransformServiceによる伝播ON/OFF、既存演算の共役変換、単一Undo、ツールの逆変換入力、変形下のヒット判定・スナップ・色取得を接続する。キャンバスの伝播設定は保存・GUIのみで、変形ツールへの接続は未実装。
9. スタックモデルとGUI、パンくず、ビンモーダル、Pointerドラッグ、ページへ戻る操作、作業矩形を実装する。
10. プロジェクトv11／履歴v9／DBv7／クリップボードv4への変更、新リソース形式、全履歴分岐の復元・回収を完成する。現段階ではバージョンを変更していない。
11. 旧親子選択以外に残る親子依存処理、旧リンク同期、ページ大ラスターと移行コードを撤去する。
12. 承認プランの全GUIシナリオと3ケースの性能検証を実施する。

## 実施した確認

- `npm run build`（型チェックと本番ビルド）。既存の大きなバンドルについてViteの警告あり。
- `npm test`（最終確認で57ファイル／278テストがすべて通過）。
- ブラウザ `http://localhost:5174/` で、キャンバス作成→内部ラスター追加→トランスフォーム追加→X移動12mm→Undoで0mm→Redoで12mm→リロード後も構造と12mmを復元、を確認。
- 既存親子データが残った別オリジンでは復元拒否を確認。互換実装は追加していない。
