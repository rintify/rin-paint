# レイヤー刷新の作業記録

更新: 2026-09-14。作業継続中。承認プラン全体の完了宣言ではない。
今回のユーザー指示によりブラウザ検証は実施しない。

## エディターへ接続済み

- キャンバス隔離合成、同一スコープのマスク・問い合わせ、無効参照の保持と警告、フラットなヒエラルキー、スタック表示と操作。
- ビンのモーダル・Pointerドラッグ・登録／リンク追加ボタン・編集対象切替・ページへ戻る操作。ビンごとの表示、選択、履歴、作業矩形の保存。
- ビン登録は先に実体を保存し、ページ履歴は参照変更と以前のローカル状態のみを保持。Undo/Redoでビン側の編集を巻き戻さない。
- 全レイヤーの素材参照アドレスをDocumentKeyに変更。ビンからページを参照するデータを拒否し、ビンのリンク候補にページを出さない。
- ラスターの実体はRasterSurface/SparseRasterの符号付き256px不変タイル。ページ大Canvas、遅延確保フラグ、ページ内走査方式の履歴差分、旧キャプチャCanvasを撤去。
- ペン、消しゴム、塗りつぶし、ぼかし、部分選択、履歴、保存、表示、サムネイルへ疎なラスターを接続。透明タイルを削除し、遠隔の描画の間を確保しない。
- ラスター内容の読み取り時リンクと最初の編集時の内容COW。内容だけの解除、Undo/Redo、GUIからの再リンクを接続。
- ラスター配置はmm行列。全体移動は配置を変更し、画素内容を変更しない。通常表示は固有PPI・原点・配置を反映。
- ペンはブラシ面積を含め、ぼかし・塗りつぶし・輪投げは対象領域を含め、固有PPIと上位演算を逆変換。射影要求を分割して中間画像を制限。
- 保存状態と物理パラメータ履歴はmm。文字サイズもmm。単位不明の保存形式やコピー時のpx再スケール経路を撤去。
- ページPPI変更は単独所有ラスターのみ再サンプル。ビン・共有内容を変更せず、前後の不変リビジョンをUndo/Redoで復元。
- 保存レコードの共通parentId/childIdsを撤去。キャンバスだけがScopeを保存し、履歴復元・コピー・ビン・読み込みは配置をスコープから取得。
- プロジェクトv11、履歴v9、DBv7、クリップボードv4。ビンと履歴をプロジェクトに含め、同一Blob内容はハッシュで重複排除。ビン読み込みの検証を追加。
- 自動保存は編集対象、表示、履歴を捕捉し、モデルとメタ情報を同一DBトランザクションで保存。
- トランスフォームの射影合成、相似変形の伝播ON、既存演算の共役変換、伝播OFFの末尾演算自動追加、単一Undo/Redo。

## 継続して実装する項目

1. CanvasLinkServiceで構造追従・子の抑制／配置差分・編集済み削除子の独立化・GUI復元を接続済み。残りは未編集の継承子を保存用に全複製せず、構造差分だけから復元する永続モデルへの統合。
2. 新ProjectRepository/LayerEntityの共有実体索引を実行時へ統合する。実行時LayerCommonからparentId/childIdsを撤去済み。子一覧はCanvasLayerだけが所有し、所属はそこから導出する。GUIの親IDは表示用の派生値。
3. 削除の自動独立化、編集済み子孫の保護、条件付き再リンク、削除済みソースを指す古い履歴を永続モデルへ接続する。
4. 図形・画像・文字の実行時pxキャッシュを含むmm統一を完成する。一般の非相似変形をローカル行列で保持し、直接ハンドル編集・スナップ・空間効果の座標系を統合する。
5. RasterStoreの圧縮タイル索引・全分岐のリソース回収を主モデルへ接続する。現状はSparseRasterの不変タイルを圧縮したRasterTileResourceとして保持し、展開画素は128MiB LRU。保存はSparseRaster形式のBlob。
6. Workerフォールバック、画像デコードと描画/GPU合計64MiBの予算を全経路へ適用する。現状の射影CPUフォールバックは同期。
7. 共有キャンバス、削除、保存復元まで通る統合テストと指定3ケースの性能確認。ブラウザは使用しない。
