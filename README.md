# rin-paint

React + TypeScript + Canvas 2D 製のペイントアプリ。

## 主な機能

- 筆圧対応のペン (Pointer Events + coalesced events)。ペンごとの詳細設定で筆圧ブレ補正と入り・抜きを調整でき、ペン色に「透明」を指定すると消しゴムとして描ける
- パラメトリック図形ツール (直線 / 四角形 / 楕円)。1図形ずつ専用レイヤーへ保存され、位置・寸法・色・線幅を後から編集・転写できる
- ツールインスタンス制: ツール欄の設定メニューで追加・ドラッグ並べ替え・削除でき、色・太さをインスタンスごとに記憶する
- 輪投げ選択 (輪郭のマーチングアンツ表示 / 移動 / 拡大縮小 / 回転 / 複製 / 「自由変形」トグルで角を個別に動かすワープ変形)
- 無制限の親子レイヤー (作成 / サブツリー削除 / ドラッグ並べ替え・入れ子 / 不透明度 / 合成モード / 下と統合)
- 対象区間を透明キャンバスで分離する効果レイヤー (色調補正 / 外側縁どり / 複数マスクのOR合成によるクリップ)
- 画像ツール (クリックまたはドラッグ＆ドロップで配置。登録済み画像ツールの幅・高さに収まるよう拡大縮小し、長方形と同じ操作・親への転写・差し替えができる)
- キャンバスサイズ変更 (メニューから。内容は左上基準で保持)
- キャンバス表示のパン / 回転 / 拡大縮小
  - タッチ: 2本指ドラッグ / ピンチ / ひねり
  - マウス: ホイールでパン、⌘(Ctrl)+ホイールでズーム、Shift+ホイールで回転、Space+ドラッグ or 中ボタンドラッグでパン
  - 右下の倍率チップをクリック (または ⌘0) で表示リセット
- 樹状の履歴 (undo 後に描いても以前の分岐が残る)。変更タイルだけを PNG 圧縮して保持する省メモリ設計。分岐点では「進む」ボタンを押したときにどちらへ進むか選べる
- スポイトツール (選択レイヤー／最終描画色を切り替え、図形・文字・透明にも対応)。0.5秒以上の長押しでも、一覧の最初のスポイト設定を使って同じルーペ操作ができる
- 色履歴パレット
- IndexedDB への自動保存とリロード時の復元。プロジェクトデータと、ツール配置・色履歴・タイムラプスON/OFFなどのアプリ設定を独立して保存
- ヘッダーの「⋮」メニューから: PNG 書き出し / プロジェクの入出力 (.rinpaint) / アプリ設定の入出力 (.rinsettings) / タイムラプスの WebM 書き出し

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # 型チェック + 本番ビルド
```

## 構成

- `src/engine/` — React に依存しない描画エンジン (合成、ツール、履歴、タイムラプス、永続化)
- `src/state/` — zustand ストア (UI と エンジンの同期)
- `src/components/` — 左パネル UI とキャンバスビュー

ツールは `src/engine/tools/types.ts` の `Tool` インターフェースを実装して
`PaintEngine` の `tools` に登録するだけで追加できます。
